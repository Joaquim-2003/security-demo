## 1.1 三个核心模块如何配合

```text
JWT
│
├─ 解决“你是谁”
├─ 验证 Token 是否可信、是否过期
└─ 从 Token 中恢复当前用户身份
        │
        ▼
Spring Security
│
├─ 保存当前请求的认证身份
├─ 控制哪些接口需要登录
└─ 为后续权限判断提供 Authentication
        │
        ▼
RBAC
│
├─ 解决“你能做什么”
├─ 根据用户查询角色与权限
└─ 判断当前用户是否拥有目标权限
        │
        ▼
业务执行
        │
        ├─ 正常完成 ─────────────► 返回成功结果
        │
        └─ 出现异常
              │
              ▼
        全局异常处理
              │
              ├─ 业务异常
              ├─ 参数校验异常
              ├─ 方法级权限异常
              └─ 系统异常
              │
              ▼
        转换为统一错误响应
```

可以将整个体系概括为：

```text
JWT
“你是谁”
    ↓
Spring Security
“保存并管理当前身份”
    ↓
RBAC
“你能做什么”
    ↓
业务逻辑
    ↓
全局异常处理
“发生错误时统一兜底”
```

## 2.1 当前项目中的异常分工

```text
未登录 / JWT 非法 / JWT 过期
        │
        ▼
JwtAuthenticationEntryPoint
        │
        ▼
401 Unauthorized


已认证，但 @PreAuthorize 权限不足
        │
        ▼
AccessDeniedException
        │
        ▼
GlobalExceptionHandler
        │
        ▼
403 Forbidden


Filter Chain 层直接配置权限且授权失败
        │
        ▼
JwtAccessDeniedHandler
        │
        ▼
403 Forbidden


业务异常 / 参数校验异常 / 系统异常
        │
        ▼
GlobalExceptionHandler
        │
        ▼
统一错误响应
```

当前项目的具体业务权限主要使用：

```java
@PreAuthorize("hasAuthority('xxx')")
```

因此日常 RBAC 权限不足时，主要走：

```text
@PreAuthorize
    ↓
AccessDeniedException
    ↓
GlobalExceptionHandler
    ↓
403
```

而 `JwtAccessDeniedHandler` 主要作为 Security Filter Chain 层授权失败时的 403 处理器保留。

# 3. 最终核心链路

整个项目可以最终压缩成下面这条主线：

```text
HTTP Request
      ↓
JWT 校验
      ↓
获取 userId
      ↓
查询用户
      ↓
查询 RBAC 权限
      ↓
组装当前登录用户
      ↓
建立 Authentication
      ↓
保存到 SecurityContext
      ↓
进入 Controller
      ↓
@PreAuthorize 检查权限
      ↓
┌──────────────┬───────────────┐
│              │               │
未认证        无权限           有权限
│              │               │
▼              ▼               ▼
401            403           正常执行
                               │
                               ▼
                              200
```

异常处理作为旁路统一工作：

```text
业务异常
参数校验异常
方法级权限异常
系统异常
    │
    ▼
GlobalExceptionHandler
    │
    ▼
统一错误响应
```

## 4. 核心理解

```text
JWT
负责认证：
“这个请求是谁发出的？”

        ↓

Spring Security
负责管理认证上下文：
“当前请求的登录身份是什么？”

        ↓

RBAC
负责授权：
“这个用户有没有执行当前操作的权限？”

        ↓

Global Exception Handler
负责异常兜底：
“如果执行过程中出现问题，如何统一返回错误？”
```
